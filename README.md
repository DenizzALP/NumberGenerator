# Number Generator

This is a small side project that visualizes numbers from 0 up to a user-defined limit. The application classifies each number as:

- *Prime* numbers (displayed with a red background)
- *Even* non-prime numbers (displayed with a green background)
- *Odd* non-prime numbers (displayed with a yellow background)

The goal of this project is to provide a simple visual tool to demonstrate basic number classification using colors.

## How it works

1. The user enters a number into an input field.
2. The script generates all numbers from 0 up to the given number.
3. Each number is displayed with a background color based on its type (prime, even, odd).

This project uses only HTML, CSS, and vanilla JavaScript. It does not rely on any external libraries or frameworks.

## Project Structure

- index.html – Contains the markup, styling, and script all in one file.

## Usage

1. Clone or download the repository.
  - git clone https://github.com/DenizzALP/NumberGenerator.git
2. Open index.html in your browser.
3. Enter a number and click the "Generate Numbers" button.
